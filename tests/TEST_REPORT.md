# Отчёт автоматизированного тестирования Local Transfer

## Среда фактического запуска

- ОС среды исполнения: Linux-контейнер, не Windows 11.
- Python: 3.13.5.
- pytest: используется установленная в среде версия.
- HTTPX: 0.28.1.
- psutil: 7.2.2.
- API тестируется независимо от веб-интерфейса через FastAPI TestClient; отдельный тест поднимает настоящий Uvicorn на loopback TCP.

## Результаты

Последний полный запуск:

```text
python -m compileall -q app tests  -> успешно
node --check web/app.js            -> успешно
python -m pytest -q                -> 64 passed in 4.37s
```

Отдельный запуск теста памяти:

```text
python -m pytest -q tests/test_memory_integration.py -s
1 passed in 1.85s
server RSS baseline=111.3 MiB, peak=112.4 MiB, growth=1.1 MiB; payload=24.0 MiB
```

Измерение RSS относится только к отдельному процессу Uvicorn в текущем Linux-окружении. Это не гарантия аналогичного результата на Windows или для любого размера файла; тест подтверждает наблюдаемое потребление памяти в одном воспроизводимом сценарии.

## Покрытые автоматические сценарии

- точное сравнение байтов и SHA-256 при загрузке/скачивании пустых, текстовых, бинарных, Unicode- и разноразмерных файлов;
- файлы размером до 8 МиБ в API-тесте и 24 МиБ в реальном Uvicorn-тесте;
- размер блока записи не превышает `chunk_size`;
- одинаковые имена и восемь параллельных загрузок без потери содержимого;
- превышение лимита файла и квоты;
- некорректные JSON, параметры текста и лимит истории;
- удаление, повторное скачивание и повторное удаление;
- path traversal, управляющие символы и повреждённые метаданные;
- ошибка публикации/записи, отсутствие частичного файла и успешная последующая передача;
- недостаток свободного места через безопасную подмену результата `disk_usage`;
- симуляция прерывания тела запроса после частичного блока и восстановление последующего запроса;
- удаление осиротевшего файла при восстановлении;
- реальная передача 24 МиБ через Uvicorn с проверкой SHA-256 и выборкой RSS.

## Не пройденные тесты

На момент последнего полного запуска: **нет**. Все 64 теста прошли.

Во время разработки четыре новых теста сначала завершились ошибкой из-за слишком малого тестового лимита и неверного ожидаемого кода ошибки; тестовые предусловия и ожидания исправлены, после чего полный набор прошёл. Это не следует считать скрытыми успешными результатами исходного запуска.

## Не проверено фактически

- выполнение набора на Windows 11;
- физический iPhone и Safari;
- доступ через точку доступа iPhone и IPv4-интерфейс Windows;
- реальные правила и профили Windows Firewall;
- физическое заполнение диска (проверяется только безопасной имитацией свободного места);
- отключение реального Wi-Fi во время передачи; сетевой разрыв симулируется на уровне тела запроса;
- крупные файлы, близкие к лимиту 2 ГиБ;
- отказ диска/файловой системы и аварийное завершение процесса в каждой точке между публикацией файла и записью SQLite;
- несколько процессов Uvicorn или общий каталог нескольких экземпляров — эта конфигурация не поддерживается.

## Ограничения измерения памяти

RSS измеряется периодическим опросом процесса Uvicorn через `psutil` во время потоковой отправки 24 МиБ с небольшими задержками между блоками. Из-за дискретного опроса очень короткий пик может быть пропущен. Порог теста — рост RSS менее 20 МиБ для 24-МиБ файла; в текущем запуске измерен рост 1.1 МиБ. Тест не измеряет память клиента HTTPX и не доказывает ограниченность памяти для всех возможных условий нагрузки.
