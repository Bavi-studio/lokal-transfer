# Local Transfer

Локальный файловый и текстовый обменник на FastAPI/Uvicorn. Интерфейс обслуживается самим приложением; внешние CDN, веб-шрифты и сетевые библиотеки не используются. Загрузка передаёт `application/octet-stream` потоково во временный файл.

## Требования

- Windows 11;
- Python 3.13 или 3.14 с Python Launcher (`py`);
- браузер на iPhone и подключение Windows к точке доступа iPhone для локальной передачи.

## Быстрый запуск

1. Распакуй каталог проекта в папку, доступную только твоей учётной записи Windows.
2. Дважды щёлкни `run.bat` или запусти его из `cmd.exe`.
3. При первом запуске скрипт создаст `.venv` и установит зависимости из `requirements.txt`. Для первой установки обычно нужен интернет либо заранее подготовленный локальный набор wheel-файлов. Сам обменник после установки работает без интернета.
4. Скрипт попытается определить IPv4-адреса активных интерфейсов Windows. Если найден ровно один адрес, он будет использован. Если адрес не определён, сервер запустится только на `127.0.0.1`; если найдено несколько адресов, скрипт попросит явно выбрать интерфейс.
5. Открой показанный адрес в браузере. Для остановки нажми `Ctrl+C` в том же окне.

Сервер не устанавливается как служба, не запускается автоматически при входе в Windows и не создаёт скрытый фоновый процесс.

## Подключение iPhone

1. Подключи Windows к точке доступа iPhone.
2. В PowerShell выполни `ipconfig` и найди IPv4-адрес интерфейса, который подключён к точке доступа. Не используй адрес `127.0.0.1` на iPhone: он обозначает сам iPhone, а не компьютер Windows.
3. Если запуск сообщил несколько интерфейсов или выбрал неправильный, в PowerShell перед запуском установи переменную, например:

   ```powershell
   $env:LOCAL_TRANSFER_HOST = "192.168.43.123"
   $env:LOCAL_TRANSFER_PORT = "8000"
   .\run.bat
   ```

   Замени пример на фактический IPv4-адрес из `ipconfig`. Не задавай `0.0.0.0`: выбери конкретный интерфейс.
4. На iPhone подключись к той же точке доступа и открой `http://<IPv4-Windows>:8000` в Safari.
5. При первом запуске токен генерируется случайно и сохраняется в `data/.access-token`. Прочитай его локально на Windows и введи в интерфейсе. Не пересылай его и не помещай в скриншоты или публичные журналы.

## Каталог передачи и лимиты

По умолчанию файлы, база метаданных и токен находятся в `data/` внутри каталога проекта. Для изменения места хранения задай `LOCAL_TRANSFER_DATA_DIR` относительным путём внутри каталога проекта, например:

```powershell
$env:LOCAL_TRANSFER_DATA_DIR = "data-private"
.\run.bat
```

Для нестандартного абсолютного пути (не рекомендуется для обычного использования) явно включи разрешение: `$env:LOCAL_TRANSFER_ALLOW_EXTERNAL_DATA_DIR = "1"`. Это осознанный обход защиты от случайного выбора системной или произвольной папки.

Абсолютные пути и `..`, позволяющие выйти за пределы проекта, по умолчанию запрещены. Для намеренного хранения вне проекта нужно дополнительно задать `LOCAL_TRANSFER_ALLOW_EXTERNAL_DATA_DIR=1`; делай это только если осознанно выбираешь каталог и проверил его ACL. Перед первым запуском выбранного каталога убедись, что доступ к папке имеет только твоя учётная запись Windows. Не помещай данные в `web/`.

Настраиваемые параметры задаются переменными окружения перед запуском:

- `LOCAL_TRANSFER_MAX_FILE_SIZE` — размер одного файла в байтах (по умолчанию 2 ГиБ);
- `LOCAL_TRANSFER_MAX_TEXT_SIZE` — размер текста в байтах (по умолчанию 1 МиБ);
- `LOCAL_TRANSFER_MAX_CONCURRENT_UPLOADS` — одновременные загрузки (по умолчанию 2);
- `LOCAL_TRANSFER_MAX_STORAGE_BYTES` — общий лимит файлов (по умолчанию 10 ГиБ);
- `LOCAL_TRANSFER_PORT` — TCP-порт (по умолчанию 8000);
- `LOCAL_TRANSFER_HOST` — конкретный IPv4-адрес для прослушивания;
- `LOCAL_TRANSFER_ALLOWED_HOSTS` — дополнительные разрешённые значения Host через запятую.

Не задавай `LOCAL_TRANSFER_TOKEN` для обычного первого запуска: сервис создаст случайный токен. Если задаёшь его вручную, используй секрет не короче 32 ASCII-символов.

## Брандмауэр Windows

Не отключай Windows Defender Firewall целиком. Если Windows предлагает разрешить доступ, разрешай его только для нужного частного профиля и только если понимаешь, какой интерфейс используется. Если правило нужно создать вручную, используй TCP-порт, выбранный для сервера (по умолчанию 8000), конкретный локальный IP-адрес Windows и профиль `Private`; по возможности ограничь удалённые адреса подсетью точки доступа. Не создавай правило для всех портов, всех профилей и всех сетей. Удаляй правило, когда обменник больше не нужен.

## Диагностика

- **`Python Launcher 'py' not found`**: установи Python 3.13/3.14 с официального установщика и включи Python Launcher.
- **Не удалось создать `.venv`**: проверь установку Python командой `py -0p`.
- **Установка зависимостей не удалась**: проверь доступ к PyPI на первом запуске. В дальнейшем зависимости можно устанавливать из подготовленных wheel-файлов; внешний интернет не нужен для передачи файлов.
- **Порт занят**: закрой другой экземпляр обменника или установи другой `LOCAL_TRANSFER_PORT`. Не завершай неизвестный процесс принудительно.
- **IPv4 не определён**: запусти `ipconfig`; назначь `LOCAL_TRANSFER_HOST` адресу нужного интерфейса.
- **iPhone не открывает страницу**: проверь, что устройства используют точку доступа, адрес не `127.0.0.1`, сервер слушает нужный интерфейс и Windows Firewall разрешает TCP-подключение к выбранному порту.
- **Токен не найден**: проверь `data/.access-token` либо каталог, заданный `LOCAL_TRANSFER_DATA_DIR`.
- **Диск заполнен**: освободи место; не удаляй вручную файлы из `data/files` или базу SQLite во время работы сервера.

## API

Все операции, кроме `GET /api/health`, требуют `Authorization: Bearer <token>`.

- `GET /api/health`
- `GET /api/files`
- `POST /api/files?filename=<URL-encoded-name>` — необработанные байты в теле запроса (`application/octet-stream`)
- `GET /api/files/{id}` — авторизованное скачивание
- `DELETE /api/files/{id}`
- `GET /api/text?limit=100`
- `POST /api/text` — JSON `{"text":"..."}`
- `POST /api/files/{id}/download-ticket` — одноразовое разрешение скачивания на 60 секунд
- `GET /api/downloads/{ticket_id}` — скачивание с короткоживущим HttpOnly-cookie

## Проверки

В активированном окружении проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q app tests scripts
node --check web/app.js
```

Проверка состояния после запуска:

```powershell
Invoke-RestMethod "http://127.0.0.1:8000/api/health"
```

Для проверки через сеть используй фактический адрес Windows вместо `127.0.0.1`.

## Безопасность и ограничения

- Bearer-токен даёт полный доступ к файлам и тексту. Любой, кто получил токен и может подключиться к серверу, может читать, загружать и удалять данные.
- HTTP не шифрует токен и содержимое. Используй обменник только в доверенной локальной сети; привязывай сервер к нужному IPv4 и ограничивай входящие соединения через Windows Firewall.
- Хранилище использует hard links для публикации файла; целевая файловая система должна поддерживать hard links.
- Блокировки рассчитаны на один процесс. Не запускай несколько workers или экземпляров с одним каталогом данных.
- Проверка свободного места предварительная: другой процесс может заполнить диск во время загрузки.
